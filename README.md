# 💼 Portfolio i Animuara

Portfolio personale interaktive me animacione — seksione për aftësi, projekte dhe kontakt, me modalitet dritë/errësirë dhe slideshow projektesh. Ndërtuar me HTML, CSS dhe JavaScript.

## 🚀 Si ta hapësh

Hap `index.html` në browser — demo-ja live shfaq portfolion. Kliko katër seksionet (About, Experience, Projects, Contact) për t'i hapur, dhe provo butonin e modalitetit dritë/errësirë.
